# منصة مأرب - الواجهة الويب (مرحلة 1)

## الأهداف

1. **فصل مشروع الويب** عن تطبيق Flutter مع الاعتماد على نفس واجهات Laravel.
2. **تهيئة البنية التقنية**: React + Vite + TypeScript + React Router + React Query + Axios.
3. **رسم خريطة التوسّع** لتغطية كل وظائف التطبيق (التصفح، التسجيل، المتاجر، الدعم…).
4. **تسهيل العمل المرحلي** عبر مكونات قابلة لإعادة الاستخدام، ونظام تصميم يعكس هوية التطبيق.

## التراص التقني

| الطبقة             | التقنية                                           | سبب الاختيار                                                                 |
|--------------------|----------------------------------------------------|-------------------------------------------------------------------------------|
| Bundler / Dev      | Vite + TypeScript                                  | سرعة التطوير ودعم ESM، مناسب للـSPA الكبيرة.                                 |
| UI Library         | React 18                                           | Ecosystem ضخم، سهولة مشاركة المنطق مع فرق متعددة.                            |
| Routing            | React Router DOM                                   | يدعم nested routes، lazy loading، و data APIs.                               |
| Data Layer         | @tanstack/react-query + Axios                      | إدارة استدعاءات API، caching، retries، وتتبع الحالة.                        |
| Typing / Validation| TypeScript + Zod                                   | ضمان اتساق الهياكل القادمة من Laravel.                                      |
| Styling            | CSS Modules بسيطة + global design tokens          | الحفاظ على الهوية الحالية، قابل للتطوير لاحقاً إلى design system موسع.     |

## هيكلة المجلدات (`marib-webapp/src`)

```
app/
  config.ts            # متغيرات عامة (رابط الـAPI)
  providers/           # Context providers (React Query, إلخ)
  router.tsx           # تعريف المسارات الأساسية
lib/
  http.ts              # تهيئة axios
pages/
  HomePage.tsx         # نظرة عامة على المرحلة
  PlaceholderPage.tsx  # صفحات placeholder للروابط القادمة
  NotFoundPage.tsx
shared/
  components/
  hooks/
styles/
  global.css           # التصميم العام والهوية
```

## خريطة المراحل

1. **المرحلة 2 – بيانات التصفح**
   - صفحات الأقسام، البحث، الفلاتر، عرض تفاصيل الإعلان، وربطها بواجهات `ApiController`.
2. **المرحلة 3 – الحسابات**
   - التسجيل، تسجيل الدخول، إدارة المتجر، وربط الجلسات مع Sanctum أو JWT.
3. **المرحلة 4 – عمليات التاجر**
   - لوحة الطلبات، إدارة المخزون، الحملات، الدفعات، والدعم اللحظي.
4. **المرحلة 5 – دعم متقدم والنشر**
   - صفحات الدعم، المحادثة، اختبارات كاملة، ونشر متكامل مع Laravel أو استضافة منفصلة.

## متطلبات المرحلة التالية

- جرد الواجهات الحالية في `routes/api.php` ومطابقة كل وظيفة مطلوبة في الويب.
- تحديد التعديلات الضرورية في الـAPI (توحيد الردود، دعم pagination/filters).
- اختيار حل للمصادقة (Sanctum مع SPA أو JWT مستقل) والاتفاق على سياسة الـCORS النهائية.
- تصميم wireframes لكل صفحة قبل تنفيذ الواجهة النهائية.

> هذه الوثيقة تُحدث مع كل مرحلة لتبقى خارطة الطريق واضحة للفريق.***
