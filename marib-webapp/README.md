# منصة مأرب – مشروع الويب

هذه الحزمة هي واجهة ويب جديدة تعكس كل قدرات التطبيق (تصفح الإعلانات، المتاجر، التسجيل، الدعم…). تم إعدادها في **المرحلة 1** لتجهيز البنية التقنية والهيكل العام.

## المتطلبات

- Node.js 20+
- خادم Laravel يعمل (للاختبارات المستقبلية) على `http://127.0.0.1:8000`

## الأوامر

```bash
npm install          # مرة واحدة
npm run dev          # يشغل Vite على http://localhost:5173
npm run build        # إنتاج ملفات النشر
npm run preview      # معاينة الإنتاج
```

للتجربة مع خادم Laravel محلي، أنشئ ملف `.env` في جذر المشروع:

```
VITE_API_BASE_URL=http://127.0.0.1:8000/api
```

## الهيكلة

- `src/app`: مزودي السياق، التوجيه، الإعدادات.
- `src/pages`: الصفحات (حاليًا Landing + placeholders لباقي الأقسام).
- `src/shared`: المكونات العامة (الرأس، التخطيطات...).
- `src/lib/http.ts`: تهيئة axios مع قاعدة الـAPI.
- `src/styles/global.css`: النظام البصري المتناغم مع التطبيق.

## المراحل القادمة

1. **التصفح والبيانات العامة** – ربط الأقسام، الفلاتر، والبحث مع الـAPI.
2. **التسجيل والحسابات** – مصادقة Sanctum/JWT مع تدفقات التسجيل الخاصة بالتجار والمستخدمين.
3. **لوحة التاجر** – الطلبات، الدفعات، الحملات، والدعم اللحظي.
4. **اختبارات ونشر** – اختبارات تكاملية ونشر مشترك مع Laravel أو استضافة مستقلة.
