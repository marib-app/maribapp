# دليل نشر خادم Marib Services

يوضّح هذا الدليل كيفية تجهيز إعدادات الإنتاج وتحميل ملف البيئة الخاص بالخادم.

## 1. تجهيز ملف البيئة للإنتاج

- استخدم الملف `marib-server/.env.production` كأساس لإعداد متغيرات الإنتاج.
- حدّث القيم الحسّاسة (مثل `APP_KEY` وبيانات قاعدة البيانات وSMTP) قبل رفع الملف إلى الخادم.
- تأكد من الإبقاء على القيمة `APP_DEBUG=false` حتى لا تُسرَّب معلومات حساسة في حال حدوث أخطاء.

## 2. رفع الإعدادات إلى الخادم

1. على جهاز التطوير، انسخ الملف إلى الخادم (باستخدام `scp` أو أي أداة تفضّلها):
   ```bash
   scp marib-server/.env.production user@server:/var/www/marib-server/.env
   ```
   > غيّر مسار الوجهة وفق إعدادات الخادم لديك. نوصي بتسمية الملف على الخادم باسم `.env` حتى يتعرّف Laravel عليه مباشرة.
2. على الخادم، امنح الملف التصاريح المناسبة (لضمان وصول التطبيق إليه فقط):
   ```bash
   ssh user@server "cd /var/www/marib-server && chmod 600 .env"
   ```
3. إذا كنت تستخدم خدمة استضافة تدعم المتغيرات البيئية بدل الملفات، فانسخ القيم يدويًا من `marib-server/.env.production` إلى لوحة التحكم، مع التأكد من تعيين `APP_DEBUG=false`.

## 3. تهيئة الكاش بعد التحديث

بعد رفع الملف إلى الخادم، نفّذ الأوامر التالية داخل مجلد المشروع لتحديث الكاش الخاص بالإعدادات:
```bash
php artisan config:clear
php artisan config:cache
```

## 4. التحقق من قيمة `app.debug`

بعد اكتمال النشر، تأكد من تعطيل وضع التصحيح عبر الأمر:
```bash
php artisan config:show app.debug
```
يجب أن تُعيد الأداة القيمة `false`. إذا ظهرت قيمة مختلفة، تحقّق من الملف `.env` أو من القيم المعرّفة في خدمة الاستضافة.
